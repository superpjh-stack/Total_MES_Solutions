입력칸 ui.field(label, name, value, type, required, readonly, step)

라벨은 위, 필수는 붉은 * (aria-label). 오류 상태는 테두리 + 아래 한 줄 사유(422 의 fields[].reason). 읽기 전용은 회색 바탕. 단위는 칸 안 오른쪽.

선택칸 ui.select(label, name, options, value, required, blank='선택')

첫 항목은 빈 값(검색은 '전체', 입력은 '선택'). 필수면 빈 값으로 저장 못 한다. 옵션은 bas_code 그룹이나 마스터 조회에서.

긴 목록(품목 · 거래처 · LOT)은 select 대신 공용 팝업(CMN-05 /popup/{kind}) — 코드 입력칸 + "찾기" 버튼. 팝업 디자인은 아래.

스캔칸 ui.scan_box(action, name, label, hidden, button)

화면에 data-scan 은 하나(실제 템플릿은 autofocus — 카탈로그에서는 뺐다). 열리면 포커스, 처리 뒤 돌아와도 포커스. 알림이 떠 있어도 스캔 글자가 들어가고 Enter 가 보낸다. Web 모양은 이것 — POP 확대본은 디자이너2 pop/.

없는 번호 — 그 화면을 422 로 다시 그린다 (스캔 진입 GET ?no=)

쓰기 버튼 ui.write_button(label, allowed=user.can('F-…'), form, kind)

그 기능을 할 수 없는 역할에게는 비활성 + 이유(title + 옆 글자). 서버도 403 으로 막는다 — 버튼은 안내지 보안이 아니다. 종류: primary(저장) · 기본(보조) · ok/warn/err(판정 · 되돌림).
