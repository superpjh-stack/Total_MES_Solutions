# 바코드 규격 — 출력물 4종 공통 (디자이너3 · 2026-10-09 · 초안)

> 적용: `print/work_order.html`(지시 번호) · `label_lot.html`(LOT 번호) · `label_shipment.html`(출하 번호) · `document.html`(발행 번호).
> 인코딩은 `printing.barcode_svg(text, *, height=40)` 한 곳이 한다(`interfaces.md` §5). 양식은 그 SVG 를 자리에 넣을 뿐이다.
> 원형의 막대는 더미 패턴이다 — 실제 스캔되지 않는다.

## 1. 심볼 · 값

| 항목 | 규격 | 이유 |
|---|---|---|
| 심볼 | **Code128** (GS1 아님 · AI 없음) | 영문 대문자 · 숫자 · `-` 를 한 심볼로. 근거 사업 셋이 같은 것을 썼다 |
| 값 | **번호 글자 그대로** — 접두어 · 구분자 · 체크 문자 추가 없음 | 스캐너는 키보드다. 스캔 결과 = 번호 = `?no=` 에 그대로 들어간다(G-C13 · G-C14) |
| 허용 문자 | `A-Z` `0-9` `-` 만. 소문자 · 공백 · 한글 · 기타 기호 없음 | 채번 규칙(`sys_number_rule`)이 이 집합 안에서만 번호를 만든다. 밖의 문자가 오면 `barcode_svg` 가 `ValueError` — 조용히 바꾸지 않는다 |
| 길이 | **권장 ≤ 20자**, 상한 24자 | 50×30mm 라벨의 폭 때문(§3). 기본 채번 `WO-20261009-0001`(16자) · `LOT-20261009-0007`(17자) |
| 코드 세트 | `barcode_svg` 가 B ↔ C 를 자동 전환해 모듈 수를 최소로 | 날짜 · 순번 같은 숫자 연속은 세트 C 가 절반 폭. 16자 번호가 세트 B 만이면 222 모듈, B/C 혼합이면 약 160 모듈 |
| 사람이 읽는 글자 | 바코드 **바로 아래**, 고정폭 글꼴, 값과 글자 하나도 다르지 않게 | 스캐너가 없을 때 손으로 친다. 글자와 값이 다르면 추적이 끊긴다 |
| 체크섬 | Code128 모듈러 103 (심볼 안) | 별도 표기 없음 |

## 2. SVG 모양 (`printing.barcode_svg` 출력)

```html
<svg class="barcode" viewBox="0 0 {총 모듈 수} 100" preserveAspectRatio="none"
     shape-rendering="crispEdges" role="img" aria-label="LOT-20261009-0007">
  <rect x="10" width="2" height="100"/> …   <!-- 검은 막대만. x · width 는 모듈 단위 정수 -->
</svg>
```

- `viewBox` 가로 = quiet zone 10 + 심볼 모듈 + quiet zone 10. 세로 100 고정. **실제 크기는 양식의 CSS(`width` · `height`)가 정한다** — `preserveAspectRatio="none"` 이라 가로 세로를 따로 늘릴 수 있다.
- 색은 `fill:#000` 고정(토큰 쓰지 않는다 — 다크 모드 · 팩 색이 바코드에 닿으면 안 된다). 배경은 투명 → 용지 흰색.
- `shape-rendering="crispEdges"` 필수 — 안티앨리어싱이 좁은 막대를 회색으로 뭉갠다.
- `aria-label` = 값. 화면 낭독 · 테스트가 값을 읽는다. 텍스트 노드는 넣지 않는다(복사 때 값이 두 번 붙는다).
- `height` 인자는 mm 가 아니라 "양식이 쓸 기본 높이 힌트" 다. 양식이 CSS 로 덮는다.

## 3. 크기 · quiet zone — 양식별

| 양식 | 바코드 폭 × 높이 | 모듈 X (최소) | quiet zone (좌우 각) | 글자 |
|---|---|---|---|---|
| 작업지시서 A4 | 62 × 14mm | 0.25mm | ≥ 2.5mm (SVG 10 모듈에 포함) | 10pt 고정폭 |
| LOT 라벨 100×50 | 80 × 13mm | 0.33mm(세트 C 혼합 기준) | ≥ 6mm | 12pt |
| LOT 라벨 50×30 | 42 × 8mm | **0.19mm** — 세트 B 만 쓰면 모자란다 | ≥ 2.5mm | 8pt |
| 출하 라벨 100×50 | 60 × 12mm | 0.25mm | ≥ 5mm | 11pt |
| 성적서 A4 | 58 × 12mm | 0.25mm | ≥ 2.5mm | 9.5pt |

- **높이 최소 8mm**(50×30), 그 밖 ≥ 12mm. 손 스캐너는 높이 10mm 이상에서 각도 여유가 생긴다.
- **모듈 X 최소 0.19mm**(203dpi 라벨 프린터 1.5 dot — 실제로는 2 dot = 0.25mm 로 올라간다). 50×30 에서 번호가 20자를 넘으면 세트 C 로도 42mm 에 들어가지 않는다 → 라벨 크기를 100×50 으로 올리거나 채번 자릿수를 줄인다. **번호를 자르지 않는다.**
- quiet zone 은 SVG 안(10 모듈)과 라벨 안쪽 여백(3mm, 절단 오차)을 합쳐 확보한다. 라벨 테두리 선을 바코드 옆에 긋지 않는다.
- 브라우저 인쇄는 "배경 그래픽" 을 끄고도 막대가 나온다(`<rect fill>` 은 배경이 아니다). 단 `.status[data-status="승인"]` 같은 흰 글자 검은 면은 `print-color-adjust:exact` 가 필요하다.

## 4. 라벨 프린터(ZPL)로 갈 때 바뀌는 것 — `PrintAdapter` 교체(E7)

| 항목 | 브라우저 인쇄(코어 기본) | ZPL 드라이버(팩) |
|---|---|---|
| 바코드 | `barcode_svg` 의 SVG | 프린터 내장 명령 `^BCN,{높이 dot},Y,N,N` + `^FD{값}^FS` — SVG 를 보내지 않는다. 값은 똑같이 번호 글자 그대로 |
| 코드 세트 | `barcode_svg` 가 고른다 | `^BC` 의 자동 모드(`N` 뒤 `A` 또는 생략) 에 맡긴다. 결과 심볼은 같은 값을 담으므로 스캔 결과가 같다 |
| 단위 | mm · pt (CSS) | dot. 203dpi = 8 dot/mm, 300dpi = 11.8 dot/mm. 양식의 mm 를 dot 으로 환산한 좌표표를 드라이버가 가진다 |
| 글꼴 | 시스템 글꼴 | 프린터 내장 글꼴(`^A0`). 한글은 프린터에 글꼴이 있어야 한다 — 없으면 품목명을 그래픽으로 보내거나(`^GF`) 코드만 찍는다. **미확정 — 프린터 기종이 정해진 뒤** |
| 두 줄 attrs | CSS 말줄임 | 글자 수 상한(100×50 은 약 36자 · 50×30 은 약 24자)을 드라이버가 자른다. 잘린 것은 라벨에만 — DB 값은 그대로 |
| 사람이 읽는 글자 | 바코드 아래 `.lotno` | `^BC…,Y` 의 자동 글자 또는 별도 `^FO/^FD`. 값과 다르게 찍히면 안 된다 |
| 출력 결과 | 브라우저가 가진다(`PrintResult` 는 `sent=False`) | `PrintResult(sent, printer, message)` 를 돌려주고 실패는 422 가 아니라 **화면 알림 + 재시도 버튼** — 라벨을 못 찍었다고 LOT 이 없어지면 안 된다 |
| 미리보기 | 인쇄용 화면 그 자체 | 같은 인쇄용 화면을 미리보기로 두고 "프린터로 보내기" 를 `ui.print_button` 옆에 추가 |

ZPL 로 가도 `templates/print/label_*.html` 은 남는다 — 프린터가 없을 때의 대체이자 미리보기다.

## 5. 스캔 왕복 검증 절차 (G-C14 — QA3 가 그대로 쓴다)

전제: 키보드 입력형(USB HID) 스캐너 · 접미 Enter 설정 · 코어 시드(`make db-seed`).

| # | 단계 | 기대 | 어긋나면 |
|---|---|---|---|
| 1 | POP-02 에서 작업 종료 → 생산 LOT 이 생긴다 → 안내의 "라벨 출력" → `GET /pop/labels?lot=<id>` | 100×50 라벨 한 장. 바코드 아래 글자 = `lot.lot_no` | 글자가 다르면 `label_for` 결함 |
| 2 | 라벨을 종이(또는 화면)에서 스캔 → 메모장에 찍힌 글자 확인 | `lot_no` 와 **한 글자도 다르지 않다** + 줄바꿈 1 | 앞뒤 공백 · 소문자 · 끊김이 있으면 `barcode_svg` 결함(모듈 폭 · quiet zone) |
| 3 | POP-03 투입 스캔 화면을 열고 스캔칸(`data-scan`)에 포커스 → 라벨 스캔 | 그 LOT 이 열린다(`?no=` → 200). 다른 LOT 이 열리면 안 된다 | 422 재렌더면 번호 불일치 — 2 를 다시 본다 |
| 4 | 없는 번호 라벨(예: 글자 하나 지운 것)을 스캔 | **그 화면이 422 로 다시 그려지고** 스캔칸 포커스 유지. 오류 화면으로 가지 않는다 | 오류 화면으로 가면 라우터 결함(api-contract §2) |
| 5 | 원재료 LOT 라벨(`/mat/lots/{id}/label`) → POP-03 투입 스캔 | 투입 1건 = 스캔 1회. 같은 라벨을 두 번 스캔하면 2건(의도) | |
| 6 | 작업지시서의 지시 번호 바코드 → POP-01 작업 목록 스캔칸 | POP-02 로 이동(그 지시) | |
| 7 | 출하 라벨의 출하 번호 → SHP-02 스캔칸 | 그 출하가 열린다. 이어서 생산 LOT 라벨 스캔 → 출하 LOT 1건 | |
| 8 | 성적서의 발행 번호 → SHP-04 검색칸 | 그 발행본이 열린다 | |
| 9 | 50×30 라벨로 1~3 반복 | 같은 결과. 안 되면 모듈 폭(§3) 문제 — 300dpi 또는 세트 C 확인 | |
| 10 | 브라우저 인쇄 배율 100% · "페이지에 맞춤" 끔으로 인쇄한 종이에서 1~3 반복 | 같은 결과 | 배율이 걸리면 quiet zone 이 줄어든다 — 인쇄 안내에 적는다 |

기록: `outputs/qa3-채널보안.md` 에 단계별 PASS/FAIL 과 스캐너 기종 · 프린터 기종 · 번호 길이를 남긴다.

## 6. 하지 않는 것

- QR · DataMatrix — 범위 밖. 2D 가 필요하면 결정 대장(`decisions.md`)에 올린다.
- 바코드 안에 수량 · 품목 코드를 같이 싣는 것(GS1-128 AI) — 값은 번호 하나다.
- 번호에 소문자 · 공백 · 한글 — 채번 규칙이 막는다.
- 클라이언트 JS 로 바코드 그리기 — 서버 `barcode_svg` 만.
