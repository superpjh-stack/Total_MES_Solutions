레이아웃 규칙

  1. 좌측 메뉴 없음. 상단 = 「뒤로」 + 작업 전환 탭(이 채널에 허용된 화면만 — channels.pop) + 작업자 · 설비 · 시각 · 연결 상태.
  2. 스캔칸 하나. data-scan 은 화면에 하나. 열리면 포커스, 빈 곳을 눌러도 포커스 복귀, 알림이 떠 있어도 스캔 글자는 스캔칸으로.
  3. 한 화면 한 작업. 스캔 → 결과 배너 → 큰 버튼 하나. 표는 행 높이 56px 이상, 글자 20px 이상.
  4. 422 는 그 화면 재렌더. 스캔 진입 GET(?no=)의 없는 번호는 오류 화면으로 가지 않고 이 레이아웃을 422 로 다시 그린다 — 결과 배너가 빨강 · 스캔칸 유지.
  5. 폼 POST 의 422 · 쓰기 성공은 303 → 같은 화면 + 알림 팝업(#flash-data). 알림은 큰 글씨, 「확인」 · 바깥 · Esc · 빈 스캔칸 Enter 로 닫히고 포커스는 스캔칸으로.
  6. 503(DB 끊김) 은 빨간 띠 + 연결 「끊김」 + 스캔칸 비활성. 오프라인 저장은 하지 않는다 — 연결이 돌아오면 다시 스캔한다.
  7. 터치 기준. 버튼 · 탭 · 선택 56px 이상, 주 버튼 80px, 스캔칸 72px. 색만으로 상태를 말하지 않는다(글자 + 배지).
