# printfilm QA 시나리오 — 화면 조작 한 바퀴 · 역할별 권한 케이스 (기획자2 · 2026-10-09)

> 엘컴화인 `goal.md` G-22 "브라우저 한 바퀴"(기준정보 → 작업지시 → 입고 · 입고검사 → 조색 → 인쇄(POP) → 후가공 → 슬리팅 → 검사 → 출하 · 승인 → COA → 역추적)를 **표준 코어 화면 + 팩 화면 7** 로 옮겼다. QA3 가 실제 브라우저로 돌고 단계별 캡처를 `outputs/e2e/printfilm/` 에 남긴다(G-C22). 역할별 케이스는 QA1(G-C17 · `permissions.csv` 60칸).
> 계정은 코어 시드 규칙대로 역할 코드 소문자(`admin` · `prod` · `qc` · `field`) · 비밀번호는 `MES_SEED_PASSWORD`(문서에 적지 않는다). 채널은 로그인 화면의 `device` 또는 `?device=pop|mobile|board`.
> 판정은 §A 의 "기대" 열. 화면 문구는 `terms` 치환 뒤(Job · Roll · COA · 슬리팅 · splice · 고객)여야 하고, 중립어(작업지시 · 생산 LOT · 성적서 · 분할 · 합병 · 거래처)가 보이면 G-P05 FAIL.
